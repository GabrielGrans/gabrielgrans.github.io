Flextrix Identity & Access

Objetivo

A ferramenta foi desenvolvida para facilitar a rotina das equipes de IAM e SecOps. Nela, os analistas recebem itens de solicitação aprovados no ServiceNow (RITMs) e podem simular, diretamente na aplicação, ações como atribuição de acesso a grupos, redefinição de senhas, criação de usuários e recadastro de MFA.

A aplicação consulta usuários, grupos e associações no Microsoft Entra ID (antigo Azure Active Directory) por meio da API do Microsoft Graph. No laboratório, o MID Server do ServiceNow encaminhou manualmente uma RITM aprovada à API da aplicação. A solução exibe os chamados, as evidências de aprovação e os logs das simulações de acesso.

O projeto envolveu a criação de automações no Flow Designer e o desenvolvimento da interface web em TypeScript, JavaScript, HTML e CSS.
